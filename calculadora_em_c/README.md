# 🧮 Calculadora Flowgorithm

 Este projeto é uma calculadora desenvolvida no **Flowgorithm**, utilizando fluxogramas para representar a lógica do programa.

 ## ⚙️ Como funciona

 O usuário informa os valores e escolhe uma operação. O programa verifica a opção escolhida, realiza o cálculo e mostra o resultado.

 ## 🧠 Como foi criada

 A calculadora foi desenvolvida utilizando **variáveis, entradas, saídas e estruturas de decisão** no Flowgorithm. O projeto foi criado para praticar conceitos básicos de lógica de programação.

 ## 🎯 Objetivo

 O objetivo foi criar uma aplicação simples para **praticar lógica de programação e criação de algoritmos através de fluxogramas**.
