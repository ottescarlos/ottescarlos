🧮 Calculadora em C

Uma calculadora simples desenvolvida em C.

💻 Como executar

Compile o programa com:

gcc calculadora.c -o calculadora


Depois, execute:

./calculadora

📚 Objetivo

Este projeto foi criado para praticar conceitos básicos da linguagem C.

👨‍💻 Autor

Projeto desenvolvido para fins de estudo.
