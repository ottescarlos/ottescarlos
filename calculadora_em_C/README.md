Calculadora em C

Este projeto foi desenvolvido em linguagem C com o objetivo de criar uma calculadora simples e praticar os conceitos básicos de programação.

Sobre o trabalho

Durante o desenvolvimento, foi criado um programa capaz de receber números digitados pelo usuário e realizar operações matemáticas.

Para construir a calculadora, foram utilizados conceitos como variáveis, entrada e saída de dados, operadores matemáticos e estruturas condicionais.

O usuário escolhe a operação que deseja realizar, informa os valores e o programa apresenta o resultado na tela.

Desenvolvimento

O trabalho foi desenvolvido utilizando o compilador GCC e pode ser executado em sistemas como Windows, Linux e macOS.

A principal finalidade do projeto foi colocar em prática os conhecimentos aprendidos sobre a linguagem C, desenvolvendo um programa simples, funcional e fácil de entender.
