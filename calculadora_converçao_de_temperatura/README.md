🌡️ Conversor de Temperatura

Calculadora simples para converter temperaturas entre Celsius, Fahrenheit e Kelvin.

⚙️ Funcionalidades
Celsius para Fahrenheit
Celsius para Kelvin
Fahrenheit para Celsius
Fahrenheit para Kelvin
Kelvin para Celsius
Kelvin para Fahrenheit
🛠️ Tecnologias
HTML
CSS
JavaScript
🚀 Como usar
Baixe ou clone o projeto.
Abra o arquivo index.html no navegador.
Informe a temperatura e escolha as unidades.
Veja o resultado da conversão.
